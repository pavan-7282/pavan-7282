# 💼 Featured Projects

## 🚖 UGO Taxi — Ride Hailing Platform ⭐ Live on Play Store

A production-grade ride-hailing application connecting passengers and drivers through real-time ride booking, driver dispatch, trip management, notifications, and payment workflows.

**Role:** Backend Node.js Developer
**Tech Stack:** Node.js · Express.js · Sequelize · MySQL · Socket.IO · JWT · Firebase FCM · REST APIs · Payment Integration

### 🔧 My Backend Contributions

- 🔐 Developed authentication and authorization using JWT and backend middleware
- 🛠️ Developed REST APIs for passenger, driver, ride, notification, and admin workflows
- 🗄️ Designed and managed relational database models using Sequelize ORM and MySQL
- 🚖 Developed the ride booking workflow, from request through driver assignment to trip completion
- 📍 Implemented nearby-driver discovery based on location and configurable search radius
- 📡 Implemented real-time ride communication using Socket.IO
- 🔄 Handled real-time ride events: driver assignment, acceptance, rejection, arrival, trip start, completion, and cancellation
- 🔔 Integrated Firebase Cloud Messaging for ride and driver notifications
- 💳 Worked on payment-related backend workflows and transaction status handling
- ⚙️ Implemented backend business logic for customer, driver, ride, notification, and admin modules
- 🧪 Tested and integrated backend APIs using Postman
- 🚀 Worked on production backend deployment and server configuration

### 🔄 Ride Lifecycle

```text
REQUESTED → DRIVER SEARCH → DRIVER ASSIGNED → ACCEPTED
   → ON THE WAY → ARRIVED → STARTED → COMPLETED
```

Also supports driver rejection, ride cancellation, and failed-driver-search flows.

### ⚡ Real-Time Backend Architecture

```text
Customer App
     │
     │ Ride Request
     ▼
Node.js + Express
     │
     ├──────────────► MySQL (via Sequelize)
     │
     └──────────────► Socket.IO ──────────────► Driver App
```

Socket.IO handles real-time communication between the app and backend for ride-related events and status updates.

### 🔔 Notification System

Firebase Cloud Messaging powers push notifications for key ride events — driver assignment, acceptance, arrival, trip status, and other updates.

### 💡 Engineering Highlights

Real-time ride-hailing backend · Location-based driver dispatch · Multi-role backend workflows · REST API development · Socket.IO communication · Relational database design · Authentication & authorization · Push notifications · Payment workflow integration

> **Note:** UGO Taxi is a production application. The source code and confidential configuration are not publicly exposed. This section describes my role, responsibilities, and technical contributions.
