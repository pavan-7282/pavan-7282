# 💼 Featured Projects

## 🚖 UGO Taxi — Ride Hailing Platform ⭐ LIVE ON PLAY STORE

A production-grade ride-hailing application connecting passengers and drivers through real-time ride booking, driver dispatch, trip management, notifications, and payment workflows.

**Role:** Backend Node.js Developer

**Tech Stack:** Node.js • Express.js • Sequelize • MySQL • Socket.IO • JWT • Firebase FCM • REST APIs • Payment Integration

### 🔧 My Backend Contributions

* 🔐 Developed authentication and authorization using JWT and backend middleware.
* 🛠️ Developed REST APIs for passenger, driver, ride, notification, and administrative workflows.
* 🗄️ Designed and managed relational database models using Sequelize ORM and MySQL.
* 🚖 Developed the ride booking workflow from ride request through driver assignment and trip completion.
* 📍 Implemented nearby-driver discovery and driver search based on location and configured search radius.
* 📡 Implemented real-time ride communication using Socket.IO.
* 🔄 Handled real-time ride events including driver assignment, acceptance, rejection, arrival, trip start, completion, and cancellation.
* 🔔 Integrated Firebase Cloud Messaging for ride and driver notifications.
* 💳 Worked on payment-related backend workflows and transaction status handling.
* ⚙️ Implemented backend business logic for customer, driver, ride, notification, and admin modules.
* 🧪 Tested and integrated backend APIs using Postman.
* 🚀 Worked with production backend deployment and server configuration.

### 🔄 Ride Lifecycle

```text
REQUESTED
    ↓
DRIVER SEARCH
    ↓
DRIVER ASSIGNED
    ↓
ACCEPTED
    ↓
ON THE WAY
    ↓
ARRIVED
    ↓
STARTED
    ↓
COMPLETED
```

Also supports applicable **driver rejection, ride cancellation, and failed-driver-search flows**.

### ⚡ Real-Time Backend

```text
Customer App
     │
     │ Ride Request
     ▼
Node.js + Express
     │
     ├──────────────► MySQL
     │                  │
     │                  └── Sequelize
     │
     └──────────────► Socket.IO
                         │
                         ▼
                     Driver App
```

Socket.IO is used for real-time communication between the application and backend for ride-related events and status updates.

### 🔔 Notification System

Firebase Cloud Messaging is used for push notifications associated with important ride events, including driver assignment, acceptance, arrival, trip status, and other ride-related updates.

### 🗄️ Database & Backend Architecture

The backend uses:

* Node.js
* Express.js
* Sequelize ORM
* MySQL
* REST APIs
* JWT authentication
* Socket.IO
* Firebase FCM

The backend is structured around controllers, routes, middleware, services, models, and utilities to separate application responsibilities.

### 💡 Engineering Highlights

* Real-time ride-hailing backend architecture
* Location-based driver dispatch
* Multi-role backend workflows
* REST API development
* Real-time Socket.IO communication
* Relational database design
* Authentication and authorization
* Push notification integration
* Payment workflow integration
* Production application development
